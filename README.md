# 🌌 Acerca del sistema

**GesMujer Oaxaca** es un sistema ERP enfocado en la gestión de programas sociales y administrativos relacionados con el apoyo y desarrollo de mujeres, permitiendo el control centralizado de información, procesos y reportes.

El sistema está diseñado para mejorar la eficiencia operativa, la transparencia y la toma de decisiones dentro de instituciones públicas o privadas.

La plataforma permite:

- 👩‍💼 Gestión de usuarios y roles
- 📊 Administración de proyectos y programas
- 👥 Registro de beneficiarias
- 💰 Control financiero (ingresos y egresos)
- 📈 Generación de reportes estadísticos
- 🔔 Notificaciones y seguimiento
- 🧾 Control administrativo centralizado
- 📱 Interfaz responsiva

El proyecto fue desarrollado para practicar:

- Desarrollo ERP
- Arquitectura de software
- PHP / Laravel
- MySQL
- Sistemas administrativos
- Gestión de datos
- Reportería avanzada

# ⚡ Instalación

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/tu-usuario/gesmujer-oaxaca.git
```

---

## 2️⃣ Crear base de datos

- Crear base de datos:

```bash
gesmujer_oaxaca
```

- Importar:

```bash
/database/gesmujer_oaxaca.sql
```

---

## 3️⃣ Configurar conexión

Editar:

```bash
config/database.php
```

o archivo `.env` si aplica.

---

## 4️⃣ Ejecutar proyecto

### Laravel

```bash
php artisan serve
```

### PHP puro

Colocar en:

```bash
htdocs/
```

y acceder desde navegador.
